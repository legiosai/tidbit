# Pendientes

## Publicación

- "Allow GitHub Actions to create and approve pull requests". `contribution.yml` abre el PR de un término
  aceptado con `GITHUB_TOKEN`, y sin ese permiso `gh pr create` falla. Primero en la organización (legiosai →
  Settings → Actions → General); mientras esté apagado ahí, el repo no lo puede activar (la API devuelve 409).
- Dar de alta el dominio en Google Search Console y mandar `https://tidbit.legios.com.ar/sitemap.xml`.
